# Visión del Producto

## Nombre

**GNC Workshop Management System** (GWMS)

## Qué es

Un ERP especializado para talleres de montaje, revisión y mantenimiento de equipos GNC vehiculares en Argentina. No es un CRM genérico ni un proyecto de práctica: es software comercial de primer nivel.

## Problema que resuelve

Los talleres de GNC operan con planillas Excel, sistemas genéricos o papel. Pierden control de:
- Vencimientos de obleas y pruebas hidráulicas (PH)
- Historial de equipos y cilindros por vehículo
- Órdenes de trabajo y producción del taller
- Inventario de repuestos GNC
- Facturación y caja
- Cumplimiento regulatorio ENARGAS/CRPC

## Usuarios objetivo

| Rol | Necesidad principal |
|-----|-------------------|
| Dueño del taller | Visión global, ganancias, producción |
| Supervisor | Control operativo, aprobaciones |
| Recepción | Alta rápida de clientes y OT |
| Mecánico | Ejecutar trabajos, checklist |
| Caja | Cobros y arqueos |
| Depósito | Stock y movimientos |

## Objetivos del producto

1. **Control total** del ciclo de vida GNC: cliente → vehículo → equipo → cilindros → OT → factura
2. **Alertas proactivas** de vencimientos (oblea anual, PH cada 5 años)
3. **Dashboard ejecutivo** con KPIs del taller
4. **Trazabilidad completa** con auditoría de todas las acciones
5. **Escalabilidad** para múltiples sucursales (futuro)

## Diferenciadores

- Dominio GNC nativo (no adaptación de ERP genérico)
- Regulación ENARGAS/CRPC integrada
- UX premium minimalista
- Arquitectura mantenible 10+ años
- Modular: cada módulo es independiente

## Métricas de éxito

- Tiempo de recepción de OT < 3 minutos
- 0 vencimientos de oblea/PH sin alerta previa
- Dashboard con datos en tiempo real
- 99.9% uptime en producción
